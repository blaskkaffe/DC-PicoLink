Dreamcast modem in the browser

Plug a USB voice modem (as for DreamPi) or the RP2040 cable into this computer, press Connect and pick its port. The page plays the dial tone and answers the Dreamcast; the PPP, NAT and DCNet part runs in dc-modemd --relay, the program that served this page. Chrome or Edge on a desktop; leave this tab open.
