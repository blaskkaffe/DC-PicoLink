# Hardware

* [WIRING.md](WIRING.md): connecting a Raspberry Pi Pico to the Dreamcast serial port
  through a DC SD Adapter V2 (the SD-card-shaped plug build). An internal install uses
  the same signals soldered to the Dreamcast's serial port pads.
* Planned: a physical SD slot on the board's own SPI pins, and a smaller internal-mod
  version (see [docs/ROADMAP.md](../docs/ROADMAP.md)).
